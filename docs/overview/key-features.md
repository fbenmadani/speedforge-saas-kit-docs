# Key Features 

- **Multi-database tenancy**: Each tenant has its own database, ensuring data isolation and scalability.
- **Central user identity**: All users are stored in a central `users` table, allowing for easy management of user accounts.
- **Admin control surfaces**: Built-in admin interfaces for managing tenants, users, and subscriptions.
- **Plan-aware billing foundations**: Ready to integrate with billing providers like Stripe to handle subscriptions and payments.
- **Modern tech stack**: Built on Laravel 13, Livewire 4, Tailwind CSS, Alpine.js, and Flux UI for a fast and responsive user experience.
