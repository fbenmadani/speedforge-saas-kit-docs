# Intro

Let's discover **Speed Forge Saas Kit in less than 10 minutes**.

## Getting Started

Fork the repo and clone it locally.

 https://github.com/fbenmadani/sfsaas.git

```bash
git clone https://github.com/[your_repo].git
cd sfsaas
composer install
```


## Start your site

Run the development server:

```bash

php artisan serve
```
